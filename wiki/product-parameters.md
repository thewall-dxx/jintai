## 一、粒径体系

珠光颜料的效果与粒径密切相关。**粒径越小，遮盖力越强，珠光越柔和；粒径越大，闪烁感越强，遮盖力越低。**

### 粒径规格一览

产品覆盖从 **＜15 μm** 到 **1000-3000 μm** 的完整粒径区间：

| 粒径范围 | 代表型号举例 | 视觉特性 | 典型应用 |
|----------|-------------|----------|---------|
| ＜15 μm | JT110、JT9337 | 柔和珠光，高遮盖力 | 化妆品、油墨、室内涂料 |
| 5–25 μm | JT120、JT201/211/221/231 | 细腻珠光 | 粉末涂料、塑料、纺织品印花 |
| 10-60 μm | JT100、JT205/215/225/235、JT300 | 标准珠光，兼顾遮盖与闪烁 | 通用涂料、油墨、塑料（最常用规格） |
| 10–30 μm | JT9327、JT9327A | 细粒径辉黄金 | 高要求粉末涂料 |
| 30-80 μm | JT150、JT9355 | 明显珠光闪烁 | 汽车涂料、建筑涂料 |
| 30-100 μm | JT153、JT249/259/269、JT351 | 闪烁珠光 | 塑料、皮革、装饰品 |
| 40-160 μm | JT161、JT9365/9375 | 强闪烁 | 工艺品、化妆品 |
| 40-200 μm | JT163、JT363/365、JT9385、JT7417 | 强金属闪光 | 塑料、印刷 |
| 50-350 μm | JT9395 | 粗颗粒闪烁 | 特殊装饰 |
| 60-300 μm | JT183 | 粗颗粒 | 人造石材、建筑装饰 |
| 100-700 μm | JT9397 | 粗颗粒强闪光 | 装饰材料 |
| 200-1000 μm | — | 极粗闪光 | 特殊装饰效果 |
| 500-1500 μm | — | 亮片级 | 工艺品、装饰 |
| 1000-3000 μm | — | 亮片级 | 装饰、工艺品 |

> 参考：产品名称表、新人培训 — 单体粒度单位 μm

### 粒径选择原则

1. **高遮盖需求** → 选细粒径（＜15 μm 或 5-25 μm）
2. **闪烁光泽需求** → 选粗粒径（40 μm 以上）
3. **均衡型需求** → 选 10-60 μm 标准粒径
4. **粉末涂料** → 常用 10-60 μm，因细粉在粉末涂料中带电量不同，需针对性选型

## 三、包覆成分与颜色关系

珠光效果的核心是 **在基材表面沉积金属氧化物形成干涉膜**，通过调整包覆的成分和膜层厚度实现不同色系：

| 包覆成分 | 呈现效果 | 对应系列 |
|----------|----------|----------|
| 二氧化钛（TiO₂） | 银白、干涉色（白→金→红→紫→蓝→绿，随膜厚递增） | 银白、幻彩、钻石 |
| 三氧化二铁（Fe₂O₃） | 金色、古铜、红棕、酒红等暖色金属质感 | 金色、云母铁 |
| 二氧化钛 + 三氧化二铁 | 金色系列 | 金色、辉煌金 |
| 二氧化硅（SiO₂）+ 二氧化钛 | 幻彩干涉色基底层 | 幻彩系列 |
| 二氧化锡（SnO₂） | 协同包覆金色 | 金色系列 |

**包覆膜厚与干涉色对应关系（TiO₂/TiO₂+SiO₂ 体系）：**

| 膜层厚度 | 干涉色 |
|----------|--------|
| 较薄 | 银白 → 金 |
| 中等 | 红 → 紫 |
| 较厚 | 蓝 → 绿 |

> 参考：新人培训 — 产品显色核心原理、产品名称表

## 四、理化特性

依据百度百科"珠光颜料"词条的通用说明：

| 特性 | 参数 |
|------|------|
| **耐温性** | 可耐受 600~800℃ 高温 |
| **耐化学性** | 常温下酸和碱均不能侵蚀 |
| **阻燃性** | 不能燃烧、不自燃、不导电 |
| **重金属含量** | 符合安全技术标准，可用于食品包装和儿童玩具 |
| **亲水性** | 表面化学结构使其具有优良的亲水性，适用于水性涂料 |
| **亲油性** | 天然亲油性差，用于有机体系时可能需要表面处理 |

> 参考：百度百科"珠光颜料"词条 — 性质

## 五、应用领域与对应产品选型

### 粉末涂料（核心应用方向）

锦泰产品在粉末涂料领域具有专长，建议选型参考：

| 效果需求 | 推荐系列 | 推荐粒径 |
|----------|----------|----------|
| 柔和珠光 | 银白系列 JT120、JT100 | 5-25 μm、10-60 μm |
| 多彩干涉 | 幻彩系列 JT205-JT235 | 10-60 μm |
| 金属金色 | 金色系列 JT300-JT309 | 10-60 μm |
| 高亮度金属感 | 钻石珑系列 JT6xx | 10-60 μm |
| 高纯度白度 | 水晶白 JT8110、JT8151 | 10-60 μm |
| 奢华金色 | 辉煌金 JT9xxx | 视需求选 |

### 塑料

适用于所有热塑性和热固性塑料，不褪色、不灰化。

| 效果需求 | 推荐系列 |
|----------|----------|
| 标准珠光 | 银白、幻彩系列 |
| 金属质感 | 金色、云母铁系列 |
| 高亮度闪光 | 钻石珑、水晶系列 |

### 油墨

用于高档包装印刷，如烟包、酒标、防伪印刷：

- 细粒径（＜15 μm 或 5-25 μm）银白或幻彩系列
- 特殊色可考虑 JH 特调系列

### 化妆品

面部、唇部、眼部和指甲用：

- 细粒径银白系列（JT110、JT110M）
- 细粒径幻彩系列
- 高纯系列（JT6xx/JT8xx）— 高白度、高亮度，适合高档化妆品
- 水晶系列 — 合成云母基，纯度高
- 需确保符合化妆品安全标准

### 其他应用

| 应用领域 | 选型建议 |
|----------|----------|
| 陶瓷装饰 | 耐高温特性优越，各类细粒径均可 |
| 纺织品印花 | 幻彩系列、银白系列 |
| 建筑涂料 | 粗粒径（30-100 μm）闪烁效果 |
| 人造石材 | 粗粒径（60-300 μm）JT183 等 |

> 参考：百度百科"珠光颜料"词条 — 应用

## 六、使用注意事项

1. **分散**：珠光颜料为片晶状颗粒，使用时应避免高速剪切过大导致破碎，建议低速均匀分散
2. **配方兼容性**：水性体系无需额外处理；有机体系如需良好分散，建议先进行表面处理
3. **与透明颜料搭配**：珠光颜料与透明有机颜料搭配效果最佳，避免与高遮盖力颜料混用
4. **粒径筛选**：建议根据最终产品的膜厚选择合适粒径，粒径不应超过膜厚的 1/3-1/2
5. **添加量**：通常为配方总量的 1-10%，视效果需求调整
