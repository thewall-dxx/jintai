## 一、选型总体原则

珠光颜料的选型需综合考虑以下因素：

```
应用场景 → 效果需求 → 基材选择 → 粒径选择 → 颜色选择 → 确认型号
```

### 1.1 按应用场景选系列

| 应用领域 | 首选系列 | 备选系列 |
|----------|----------|----------|
| **粉末涂料** | 银白、幻彩、金色 | 钻石珑、辉煌金 |
| **汽车涂料** | 幻彩、变色龙、辉煌金 | 水晶高光系列 |
| **建筑涂料** | 银白、金色（粗粒径） | 钻石珑 |
| **塑料** | 银白、幻彩、金色 | 云母铁、着色系列 |
| **油墨** | 银白、幻彩（细粒径） | 特殊调配 JH 系列 |
| **化妆品** | 银白（细粒径）、高纯 | 水晶系列 |
| **纺织品印花** | 银白、幻彩 | 着色系列 |
| **陶瓷** | 银白、幻彩（耐高温） | 钻石珑 |

> 参考：百度百科"珠光颜料"词条 — 应用

### 1.2 按粒径选型

粒径是选型的核心参数之一：

| 效果需求 | 推荐粒径 | 说明 |
|----------|----------|------|
| **柔和珠光，高遮盖力** | ＜15 μm 或 5-25 μm | 遮盖力强，珠光细腻 |
| **标准珠光，通用型** | 10-60 μm | 兼顾遮盖力与闪烁效果（最常用） |
| **明显闪烁效果** | 30-100 μm | 珠光闪烁感强，遮盖力下降 |
| **粗颗粒闪光** | 40-200 μm | 金属闪光效果明显 |
| **极粗闪光/亮片** | 200 μm 以上 | 特殊装饰效果 |

> 参考：产品参数 — 粒径体系

### 1.3 按颜色选型

**基础色系对照：**

| 需求颜色 | 推荐产品系列 | 典型型号 |
|----------|-------------|----------|
| **白色珠光** | 银白系列、水晶白 | JT100、JT8110 |
| **金色** | 金色系列、辉煌金 | JT300、JT9305 |
| **红色干涉** | 幻彩红系列 | JT215、JT211 |
| **紫色干涉** | 幻彩紫系列 | JT219、JT223 |
| **蓝色干涉** | 幻彩兰系列 | JT225、JT221 |
| **绿色干涉** | 幻彩绿系列 | JT235、JT231 |
| **金属质感色** | 云母铁系列 | JT500（古铜）、JT504（酒红） |
| **随角变色** | 变色龙系列 | HZP20819B2（紫→蓝绿） |

## 四、客户报价流程建议

1. **确认需求**：了解客户的应用领域、效果要求、预算范围
2. **推荐系列**：根据效果需求匹配产品系列
3. **确认粒径**：确认客户需要的闪烁度或遮盖力，选定粒径范围
4. **样品提供**：寄送样品供客户测试（建议 3-5 个候选型号）
5. **技术确认**：确认产品在客户配方中的兼容性（水性/油性体系）
6. **批量报价**：确认型号后按用量报价

### 常见客户需求场景与推荐方案

| 客户需求 | 推荐方案 |
|----------|----------|
| "要白的、亮的" | 水晶白 JT8110 或银白 JT100（10-60 μm） |
| "要金色的" | 金色 JT300 系列 或 辉煌金 JT9xxx 系列 |
| "要七彩变色的" | 幻彩系列 或 变色龙系列 |
| "要金属感强的" | 钻石珑系列 JT6xxx 或 金色系列 JT3xx |
| "粉末涂料用" | 优先推荐 10-60 μm 标准粒径，银白或幻彩系列 |
| "化妆品用" | 细粒径银白 JT110/JT110M（＜15 μm） |

## 五、常见问题处理

### 客户反馈效果不佳的可能原因

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 珠光不明显 | 粒径过细或添加量不足 | 增加用量或换用粗粒径 |
| 遮盖力不够 | 粒径过粗 | 换用细粒径或搭配钛白粉 |
| 颜色不均匀 | 分散不充分 | 改进分散工艺，降低剪切速度 |
| 有颗粒感 | 粒径与膜厚不匹配 | 换用更细粒径，确保粒径 < 膜厚的 1/2 |
| 有机体系分散差 | 亲油性不足 | 使用经表面处理的型号 |
