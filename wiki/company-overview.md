## 公司简介

**福建锦泰珠光材料有限公司** 是一家专注于珠光颜料研发与生产的制造型企业。公司产品以 **"JT"（锦泰）** 为统一前缀，建立了涵盖 500 余种型号的完整产品体系。

## 核心产品定位

锦泰珠光产品以 **粉末涂料专用珠光颜料** 为核心方向，产品广泛应用于：

- **涂料** —— 粉末涂料、汽车面漆、建筑涂料、家用电器涂料
- **塑料** —— 适用于热塑性和热固性塑料，不褪色、不灰化
- **油墨** —— 高档包装印刷（烟包、酒标、防伪印刷等）
- **化妆品** —— 面部、唇部、眼部及指甲用美容化妆品
- **陶瓷** —— 提供独特光学效果的陶瓷装饰
- **纺织品** —— 织物印花产生珍珠光泽
- **其他** —— 人造石材、工艺品、皮革、搪瓷等

> 参考：百度百科"珠光颜料"词条 — 珠光颜料可广泛应用于上述领域

## 产品技术原理

珠光颜料的核心原理是 **在基材表面沉积金属氧化物**，通过调整包覆成分与膜层厚度，实现不同的色系和珠光效果。

**基材分类：**

| 类型 | 材料 | 用途 |
|------|------|------|
| 天然基材 | 天然云母 | 基础款产品的主流基材 |
| 人工合成基材 | 合成云母、玻璃鳞片、石英砂、碳酸钙等 | 高端、特殊效果产品系列 |

**核心包覆材料：** 二氧化钛（TiO₂）、三氧化二铁（Fe₂O₃）、二氧化硅（SiO₂）、氧化铝（Al₂O₃）等

**可实现的基础色系：** 白、金、红、紫、蓝、绿

> 参考：新人培训核心内容梳理

## 生产全流程

```
原材料处理 → 云母筛分 → 后段处理 → 仓库储存
```

**前端核心工序：**
- 原材料通过 **37kw 电机水碾** 进行破碎碾磨，水碎至纳米级软质粉体
- 经筛分后进行后段包覆处理

## 产品系列概览

锦泰珠光共拥有 **11 大核心系列**，覆盖从基础款到高端特效的全品类：

| 系列 | 基材 | 特点 |
|------|------|------|
| 银白系列 | 天然云母 | 按粒径划分不同型号，基础款 |
| 幻彩系列 | 天然云母 | 包覆 SiO₂、TiO₂，实现金红、紫、蓝、绿等色系 |
| 金色系列 | 天然云母 | 包覆 TiO₂、Fe₂O₃、SnO₂ |
| 着色系列 | 天然云母 | 溶剂型二次加工上色，上百个品种 |
| 云母铁系列（JT5） | 天然云母 | 核心包覆 Fe₂O₃ |
| 钻石珑系列 | 玻璃鳞片 | 兼容银白、幻彩特性 |
| 辉煌金（特金）系列 | 合成云母 | 纯度、浓度更高，颜色更艳丽 |
| 合成云母系列 | 合成云母 | 8 系列品质优于 7 系列 |
| 变色龙系列 | 玻璃/合成云母 | 随角度变色幅度大 |
| 高纯系列 | 玻璃/合成云母 | 高白度、高亮度、高纯度 |
| 水晶系列 | 合成云母 | 水晶白、水晶幻彩、水晶金色等分支 |

> 参考：新人培训核心内容梳理 — 全系列产品体系

## 型号命名规则

产品型号以 **JT（锦泰）** 开头，后续数字标识具体系列与规格：

- **JT1xx** — 银白系列（按粒径区分）
- **JT2xx** — 幻彩系列（JT205 幻彩金、JT215 幻彩红、JT225 幻彩兰、JT235 幻彩绿等）
- **JT3xx** — 金色系列
- **JT4xx** — 着色系列（溶剂型二次上色，上百个品种）
- **JT5xx** — 云母铁系列
- **JT6xx** — 钻石珑 / 高纯（玻璃基材）
- **JT7xx** — 钻石珑系列（玻璃基材）
- **JT8xx** — 水晶 / 高纯（合成云母基材）
- **JT9xx** — 辉煌金/辉黄金系列
- **JT20/24xx** — 变色龙系列
