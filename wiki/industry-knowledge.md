## 一、什么是珠光颜料

**珠光颜料**（Pearlescent Pigments）是一种光学效应颜料。它能呈现一定的金属光泽，故又称作 **具有金属光泽的非金属颜料**。珠光颜料具有金属颜料的闪光效果，又能产生天然珍珠的柔和色泽。在阳光照射时，能产生多层次的反射，反射光相互作用而呈现出柔和夺目或五彩缤纷的光泽及色彩。

> 参考：百度百科"珠光颜料"词条 — 基本简介

## 二、显色原理

珠光颜料的显色原理是 **光的干涉效应**：

1. 颜料由 **较高折射率的物质**（金属氧化物）包裹在 **较低折射率的基材** 表面
2. 光线到达不同折射率材料的界面时，被分为 **反射光** 和 **透射光**
3. 反射光和透射光互为 **补色**
4. 这种效应与日常生活中观察到的 **肥皂泡**、**溢出的油类**、**珍珠** 的颜色现象相同

> 参考：百度百科"珠光颜料"词条 — 基本简介

## 三、核心生产工艺

### 3.1 生产核心原理

在基材表面 **沉积金属氧化物**。常用的包覆氧化物包括：

| 氧化物 | 化学式 | 作用 |
|--------|--------|------|
| 二氧化钛 | TiO₂ | 银白及干涉色系（白→金→红→紫→蓝→绿，随膜厚变化） |
| 三氧化二铁 | Fe₂O₃ | 金色、古铜、红棕等暖色金属质感 |
| 二氧化硅 | SiO₂ | 干涉色基底层（含量通常 < 5%） |
| 氧化铝 | Al₂O₃ | 辅助沉积、改善表面特性 |
| 二氧化锡 | SnO₂ | 金色系列协同包覆 |

> 参考：新人培训 — 产品显色核心原理

### 3.2 生产全流程

```
原材料处理 → 云母筛分 → 后段处理 → 仓库储存
```

**各工序说明：**

1. **原材料处理（云母车间）**：通过 **37kw 电机水碾** 进行破碎碾磨，将天然云母水碎至纳米级软质粉体
2. **云母筛分**：按粒径分级筛选，得到不同细度的云母基材
3. **后段处理**：在基材表面进行金属氧化物包覆沉积（水解、煅烧等工艺），形成珠光效果
4. **仓库储存**：成品检测后入库储存

> 参考：新人培训 — 生产全流程

## 四、主要基材类型

| 基材 | 来源 | 特点 | 用途 |
|------|------|------|------|
| **天然云母** | 天然矿物 | 资源丰富、性价比高、珠光柔和 | 基础款珠光颜料的主流基材 |
| **合成云母（合成晶体云母）** | 人工合成 | 纯度更高、白度更高、耐温性更好 | 高端系列 |
| **玻璃鳞片** | 人工合成 | 透明度高、闪烁感强、光泽亮丽 | 钻石珑系列、变色龙系列 |
| **石英砂** | 天然/人工 | 特殊硬度与光学特性 | 部分特殊型号 |
| **碳酸钙** | 天然/人工 | 价格低廉 | 部分特殊型号 |

## 五、产品分类体系

### 按基材分类

| 分类 | 包含系列 |
|------|----------|
| **天然云母基** | 银白、幻彩、金色、着色、云母铁 |
| **合成云母基** | 水晶系列、高纯系列、辉煌金系列 |
| **玻璃鳞片基** | 钻石珑系列、变色龙系列（部分） |
| **混合/特殊基材** | 特殊调配系列 |

### 按效果分类

| 分类 | 特点 | 代表系列 |
|------|------|----------|
| **珠光效果** | 珍珠般柔和光泽 | 银白系列、幻彩系列 |
| **金属效果** | 金属闪光质感 | 金色系列、辉煌金系列 |
| **色彩效果** | 丰富艳丽的颜色 | 着色系列 |
| **干涉效果** | 不同角度呈现不同颜色 | 幻彩系列、变色龙系列 |
| **高纯度效果** | 高白度、高亮度、高纯度 | 高纯系列 |

### 常见色系

珠光颜料可实现六大基础色系：**白、金、红、紫、蓝、绿**，通过调整包覆膜层的厚度和成分，可衍伸出上百种颜色。

## 六、关键参数与行业术语

| 术语 | 说明 |
|------|------|
| **粒径（μm）** | 珠光颜料片晶的颗粒尺寸，以微米为单位。粒径影响闪烁感和遮盖力 |
| **包覆率** | 金属氧化物在基材表面的覆盖程度 |
| **干涉色** | 通过光的干涉效应产生的颜色，随观察角度变化 |
| **闪烁度** | 珠光颜料的闪光强度，通常与粒径正相关 |
| **遮盖力** | 颜料覆盖底材颜色的能力，通常与粒径负相关 |
| **耐温性** | 珠光颜料可耐受高温的能力（可达 600-800℃） |
| **亲水性/亲油性** | 颜料在水性或油性体系中的分散表现 |

## 七、应用领域概述

珠光颜料凭借其独特的光学效果和优良的理化性能，被广泛应用于以下领域：

| 应用领域 | 应用说明 |
|----------|----------|
| **涂料** | 汽车面漆、粉末涂料、建筑涂料、家用电器（核心应用方向） |
| **塑料** | 适用于所有热塑性和热固性塑料，不褪色、不灰化 |
| **油墨** | 高档包装印刷（烟包、酒标、防伪印刷） |
| **化妆品** | 面部、唇部、眼部和指甲用化妆品的主要着色剂 |
| **纺织品** | 织物印花呈现珍珠光泽与色彩 |
| **陶瓷** | 赋予陶瓷奇特的光学性能 |
| **其他** | 人造石材、工艺品、皮革、搪瓷、纸张等 |

> 参考：百度百科"珠光颜料"词条 — 应用

## 八、理化特性

| 特性 | 说明 |
|------|------|
| **耐化学性** | 常温下酸和碱均不能侵蚀 |
| **耐温性** | 能耐受 600~800℃ 高温 |
| **阻燃性** | 不能燃烧、不自燃、不导电 |
| **安全性** | 重金属含量低，符合安全技术标准，可用于食品包装和儿童玩具 |
| **耐候性** | 具有优良的耐候性能，不易褪色 |
| **亲水性** | 表面化学结构使其具有优良的亲水性，适用于水性涂料 |
| **亲油性** | 天然亲油性差，用于有机体系时可能需要特殊表面处理 |

> 参考：百度百科"珠光颜料"词条 — 性质

## 九、行业发展趋势

- **粉末涂料专用珠光颜料** 需求持续增长（环保型涂料方向）
- **高端基材合成云母** 的应用比例逐渐提升（追求更高纯度、亮度和耐温性）
- **变色龙/干涉色** 产品需求上升（高端装饰、防伪、汽车涂料等场景）
- 化妆品级珠光颜料对 **细粒径、高纯度** 要求不断提高
- 环保法规趋严推动 **无重金属、安全合规** 产品的开发
