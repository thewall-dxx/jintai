# 产品目录

> 信息来源：锦泰珠光产品名称表（503 条型号）、新人培训核心内容整理

锦泰珠光产品以 **"JT"（锦泰）** 为统一前缀，按基材、包覆成分和效果分为 **11 大核心系列**，全面覆盖从基础通用款到高端特效款的全品类，共 **500 余种** 产品型号。

## 一、基础通用系列

### 1. 银白系列 (JT1xx)

以天然云母为基材，包覆二氧化硅（SiO₂）、二氧化钛（TiO₂），按粒径区分不同型号，是珠光颜料的基础款。

| JT110 / JT110M | ＜15 |
| JT120 | 5–25 |
| JT100 / JT100T / JT100A | 10-60 |
| JT103 | 10-60 |
| JT173 | 10-40 |
| JT150 | 30-80 |
| JT151 | 10-100 |
| JT153 | 30-100 |
| JT161 | 40-160 |
| JT163 | 40-200 |
| JT183 | 60-300 |

共 20 种型号。

> 参考：产品名称表、新人培训 — 银白系列

## 二、色彩功能系列

| JT365 | 40-200 |

共 17 种型号。

### 4. 着色系列

以珠光颜料为基础，在云母基材上通过溶剂型工艺二次加工上色，颜色丰富艳丽，涵盖上百个品种。

主要色系：银灰、炭黑、深黑、大红、玫红、桔红、墨绿、草绿、咖啡、铜棕、紫红、酒红、宝蓝、天蓝等。

> 参考：新人培训 — 着色系列

## 三、高端特效系列

### 6. 钻石珑系列 (JT6xx，玻璃基材)

以玻璃鳞片为基材，包覆二氧化硅、二氧化钛，兼容银白和幻彩系列特性。

**钻石白：** JT6201、JT6301、JT6101、JT6501、HZP6131 等（10 种）
**钻石金：** JT6202、JT6302、JT6102、HZP6162、HZP6202 等（6 种）
**钻石红/紫/蓝/绿：** JT6203-JT6206 系列（各 6 种）
**钻石高纯白/金/红/紫/蓝/绿：** 高纯度分支型号

### 7. 合成云母系列 (JT8xx)

以合成云母为基材，采用镀膜涂晶工艺。8 系列品质优于 7 系列。

**水晶白：** JT8110、JT8110M、JT8120、JT8120M、JT8151 等（36 种）
**水晶幻彩系列：** 水晶幻彩金/红/紫/蓝/绿（各 8 种）
**水晶金色：** JT8553、JT7366、JT7363 等（6 种）
**水晶高光系列：** 高光金/红/紫/蓝/绿/白（各 3-5 种）
**水晶酒红：** JT8304、JT7534、JT7655

### 8. 辉煌金 / 辉黄金系列 (JT9xx)

以合成云母为基材，比普通金色系列纯度、浓度更高，颜色更艳丽。包覆钛、铁等成分，可实现金红、紫、蓝、绿、白等色系。

|------|-----------|
| JT9305 / JT9305A / JT9305M | 10-60 |
| JT9306 | 10-60 |
| JT9315 / JT9316 / JT9317 / JT9317A / JT9318 / JT9318C | 30-100 |
| JT9327 / JT9327A / JT9327W | 10–30 |
| JT9337 | ＜15 |
| JT9355 / JT9355B | 30-80 |
| JT9365 / JT9368 | 40-160 |
| JT9375 | 40-160 |
| JT9385 | 40-200 |
| JT9395 | 50-350 |
| JT9397 | 100-700（或 100–700） |
| JT9A05 | 10-60 |

**辉煌金（HZP 系列）：** HZP9317、HZP9385、HZP9327、HZP9397、HZP9365 等 7 种型号。

### 9. 变色龙系列 (JT20/JT24 开头)

基材为玻璃、合成云母、金鳞片，随角度变色幅度大。基材为钛、硅基；另有铁系变色龙，为硅-钛-硅基材结构，着色成分为铁。

**双色/三色干涉系列：**

| 系列 | 示例型号 | 颜色变化 |
|------|----------|---------|
| 紫兰-蓝绿 | HZP20819B2-C2 等 | 紫 → 蓝绿 |
| 紫蓝-蓝绿 | HZP20819B5-C5 等 | 紫蓝 → 蓝绿 |
| 紫蓝-绿金 | HZP20825B3-C3 等 | 紫蓝 → 绿金 |
| 蓝绿-绿金 | HZP20825B4-C4 等 | 蓝绿 → 绿金 |
| 绿金-金红 | HZP20835B6-C6 等 | 绿金 → 金红 |

> 参考：新人培训 — 变色龙系列

### 10. 高纯系列 (JT6xx / JT8xx)

基材为玻璃或合成云母，硅-硅基材结构，仅做银白、幻彩两个色系。核心特点是 **高白度、高亮度、高纯度**。

- **型号 8 开头**（如 JT8xxx）：合成云母基材
- **型号 6 开头**（如 JT6xxx）：玻璃基材

| 分支 | 型号示例 |
|------|----------|
| 钻石高纯白 | JT6501G 等 |
| 钻石高纯金 | JT6502G、HZP6202G、HZP6302G |
| 钻石高纯红/紫/蓝/绿 | 各 2 种型号 |

### 11. 水晶系列

合成云母基材，涵盖水晶白、水晶幻彩、水晶金色、水晶高光等多个分支（见第 7 节）。
